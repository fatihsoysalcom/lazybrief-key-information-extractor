# Lazybrief Key Information Extractor

This Python script demonstrates the 'Lazybrief' concept by automatically generating a concise summary from a longer text. It extracts a high-level overview and identifies key action items or important decisions using keyword matching, aiming to save the reader's time and quickly convey essential information.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`
